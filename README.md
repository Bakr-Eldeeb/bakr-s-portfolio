# Bakr Eldeeb Portfolio

A static HTML/CSS/JavaScript portfolio using the supplied project screenshots and portrait.

## Preview locally

Option 1: double-click `index.html`.

Option 2 (recommended): run a small local server:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Deploy

You can drag the whole folder into Netlify, or deploy it to Vercel/GitHub Pages as a static site.
"# bakr-s-portfolio"
